This project contains structured lecture notes, examples, exercises, and quick-reference tables covering the fundamentals of R.

## 🎯 Purpose

The goal of this project is to provide a **practical reference and teaching resource** for students who are learning R.

Each chapter combines:

* 📖 Explanations
* 💻 Executable R examples
* 📋 Reference tables
* 🧩 Practice exercises
* 🔑 Key takeaways

The notes are designed to work both as **lecture material** and as a **quick reference while programming**.
